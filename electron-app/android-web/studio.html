GhostForge Studio

Connect to your GhostForge web server for the full studio: Job Hunter, CV improvement, agents, workflows, marketplace, chat, files and settings.

Desktop on the server machine: http://localhost:3001. On Android or another computer, use the server's LAN address or HTTPS remote address, not localhost. Sign in or pair the device on the server.

Server setup

Install the GhostForge checkout on your Mac, Windows or Linux server, then run cd web-ui, npm ci and npm run dev. For production use the documented HTTPS setup. The server must remain running.

Job Hunter fills application forms on the server's browser, not on your phone. Review each draft and approve before applying. Captchas and sign-ins still need you.

Only connect to a server you own and trust. HTTP connections are unencrypted; use HTTPS for remote access. Your server address is saved locally, never your password.
