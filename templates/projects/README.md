# Project Templates

The project template system provides ready-to-adapt starters for common stacks.

## Available templates
- `react-vite` — React + Vite + TypeScript + Tailwind + TanStack Query + Zustand + React Router
- `nextjs-i18n` — Next.js 15 + next-intl + App Router + Tailwind + TanStack Query
- `react-native-expo` — Expo SDK + NativeWind + React Navigation + TanStack Query
- `full-stack` — Next.js + tRPC + Prisma + Auth.js

## How to use
1. Copy the template directory.
2. Install dependencies.
3. Rename the project and update environment variables.
4. Extend the structure to match the target domain.
