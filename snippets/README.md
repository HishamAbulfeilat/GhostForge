# GhostForge Snippet Library

Each snippet is a Markdown file with:
- **Purpose**
- **When to use it**
- **Code** block(s)
- **Customization notes**

Recommended filename format: `kebab-case.md`.

Use via:
- TUI / docs browsing
- `/snippet list`
- `/snippet use [name]`
- `bash scripts/snippet-manager.sh`
