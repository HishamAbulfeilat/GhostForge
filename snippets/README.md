# GhostForge Snippet Library

Reusable snippets for React, Next.js, TypeScript, React Native, and related frontend workflows.

## Available snippets
| Snippet | Description |
|---|---|
| `api-hook.md` | Reusable data fetching hook template. |
| `apexcharts.tsx` | Responsive ApexCharts examples for line, bar, and area charts with RTL support. |
| `auth-interceptor.md` | Axios interceptor pattern for auth headers and token refresh. |
| `azure-ad-login.md` | Quick Azure AD login snippet for common auth flows. |
| `dnd-kit.tsx` | Keyboard-accessible sortable list powered by `@dnd-kit`. |
| `env-validator.md` | Environment variable validation helper pattern. |
| `error-boundary.md` | React error boundary and fallback UI example. |
| `export-utils.ts` | Utilities for exporting HTML, tables, Excel files, and CSV data. |
| `file-upload.tsx` | `react-dropzone` upload component with previews, validation, and progress. |
| `form-submit-handler.md` | Shared loading and submit-state handling pattern for forms. |
| `msal-auth.tsx` | MSAL browser and React provider setup with silent token acquisition. |
| `next-intl-page.tsx` | Next.js App Router and `next-intl` locale-aware page and layout example. |
| `protected-route.md` | Protected route wrapper for authenticated pages. |
| `rhf-zod-form.tsx` | React Hook Form + Zod example with files, selects, and validation. |
| `rn-safe-area.md` | Safe area wrapper pattern for Expo and React Native screens. |
| `tanstack-query.tsx` | TanStack Query v5 query, mutation, infinite query, and optimistic update patterns. |
| `tanstack-table.tsx` | Generic TanStack Table v8 setup with sorting, filtering, and pagination. |
| `tiptap-editor.tsx` | TipTap editor with toolbar, formatting extensions, and HTML output. |
| `zustand-store.md` | Documentation-oriented Zustand store example. |
| `zustand-store.ts` | TypeScript Zustand store with selectors, persistence, and devtools. |

## Usage
```bash
/snippet list
/snippet [name]
/snippet use [name]
```
