# /i18n Command

## Description
Full internationalization assistant. Extracts hardcoded strings, generates translation files, sets up the i18n library, and adds RTL (Right-to-Left) support for Arabic.

## Usage
```
/i18n setup                 → Set up i18n from scratch (installs library, creates files)
/i18n extract               → Scan codebase and extract all hardcoded strings
/i18n add-language [code]   → Add a new language (e.g. /i18n add-language ar)
/i18n rtl                   → Add RTL layout support for Arabic/Hebrew
/i18n missing               → Find strings not yet translated
/i18n validate              → Check all translation keys are consistent across languages
```

## Supported Libraries
- **Web**: `next-intl` (recommended for Next.js), `react-i18next`
- **Mobile**: `i18n-js` + `expo-localization`, `react-i18next`

### RTL Support (Web — Tailwind)
```typescript
// app/[locale]/layout.tsx
import { getLocale } from 'next-intl/server';

export default async function RootLayout({ children }) {
  const locale = await getLocale();
  const isRTL = ['ar', 'he', 'fa', 'ur'].includes(locale);

  return (
    <html lang={locale} dir={isRTL ? 'rtl' : 'ltr'}>
      <body className={isRTL ? 'font-arabic' : 'font-sans'}>
        {children}
      </body>
    </html>
  );
}
```

### RTL Support (React Native)
```typescript
// utils/rtl.ts
import { I18nManager } from 'react-native';
import * as Localization from 'expo-localization';

export const isRTL = Localization.isRTL;

export function setupRTL() {
  if (isRTL && !I18nManager.isRTL) {
    I18nManager.allowRTL(true);
    I18nManager.forceRTL(true);
  }
}

// Use logical styles (RTL-aware)
// ✅ marginStart (not marginLeft)
// ✅ paddingEnd (not paddingRight)  
// ✅ flexDirection: 'row' flips automatically in RTL
```
