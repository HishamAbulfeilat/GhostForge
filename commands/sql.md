# /sql Command

## Description
SQL developer assistant. Writes queries, generates reports, designs schemas, creates ETL scripts, and optimizes database performance.

## Usage
```
/sql query [description]          → Write a SQL query
/sql report [description]         → Generate a full report (SQL + HTML/PDF output)
/sql schema [description]         → Design or update a database schema
/sql etl [source] to [target]     → Build an ETL pipeline
/sql optimize [query or table]    → Optimize a slow query or table
/sql migrate                      → Generate a migration script
/sql seed                         → Generate seed/test data
/sql stored-proc [description]    → Write a stored procedure
/sql explain [query]              → Explain what a query does
```

## Examples
```
/sql query get all active users with their total order count and lifetime value
/sql report monthly sales by region for the last 12 months
/sql schema design a table for tracking employee timesheets
/sql optimize this query is slow: SELECT * FROM orders WHERE customer_id = 5
/sql etl from SQL Server orders table to Azure SQL Data Warehouse
/sql report top 10 products by revenue this quarter — export as PDF
```

## Workflow

### Step 1 — Gather Info
- Database type? (MSSQL / PostgreSQL / MySQL / SQLite / Azure SQL)
- Table names and columns? (or read from existing schema/migration files)
- Output format? (table, JSON, CSV, PDF report)
- Any filters, date ranges, groupings?

### Step 2 — Generate SQL
- Uses CTEs for complex queries
- Adds inline comments
- Includes indexes if new tables are created
- Adds execution plan hints for performance

### Step 3 — Wrap in Service (optional)
Generates a TypeScript/Node.js service function around the query.

### Step 4 — Generate Report (if /sql report)
- HTML table with GhostForge styling
- PDF export via Puppeteer
- Excel export via ExcelJS
- Scheduled via Azure Functions or cron

## Output Format
```sql
-- Query: Monthly Sales by Region (last 12 months)
-- Database: MSSQL
-- Generated by GhostForge SQL Agent

WITH MonthlySales AS (
  SELECT
    r.name AS region,
    FORMAT(o.created_at, 'yyyy-MM') AS month,
    COUNT(o.id) AS order_count,
    SUM(o.total_amount) AS revenue
  FROM orders o
  INNER JOIN regions r ON r.id = o.region_id
  WHERE o.created_at >= DATEADD(MONTH, -12, GETDATE())
    AND o.status = 'completed'
  GROUP BY r.name, FORMAT(o.created_at, 'yyyy-MM')
)
SELECT
  region,
  month,
  order_count,
  revenue,
  SUM(revenue) OVER (PARTITION BY region ORDER BY month) AS cumulative_revenue
FROM MonthlySales
ORDER BY region, month;
```
