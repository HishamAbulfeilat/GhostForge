# Copilot Spaces Setup — GhostForge AI Developer Toolkit

Use this guide to create a shared **Copilot Space** for the GhostForge engineering team.

## Steps

1. Go to [github.com/copilot/spaces](https://github.com/copilot/spaces) → **New Space**.
2. Name the Space: **GhostForge AI Developer Toolkit**.
3. Description: **Full-stack AI assistant for GhostForge developers**.
4. Paste the contents of `.copilot/space-config.md` into the Space instructions/context field.
5. Add repository knowledge source: **`HishamAbulfeilat/GhostForge`**.
6. Share the Space with organization members.
7. Pin the Space to the GitHub sidebar for quick access.

## Recommended follow-up

- Keep `.copilot/space-config.md` in sync with `.github/copilot-instructions.md`.
- Add `knowledge/` files as extra context documents when team conventions evolve.
- Revisit the Space after every release so commands, models, and workflows stay current.
