# New Developer Onboarding

## First-day checklist
- Clone the repo and install dependencies.
- Copy `.env.example` to `.env.local` and request secret values from the team lead.
- Read `README.md`, `.github/copilot-instructions.md`, and the `knowledge/` folder.
- Run the app locally and confirm lint/tests work.

## First-week checklist
- Review `knowledge/decisions.md` and `knowledge/patterns.md`.
- Walk through auth, API, and deployment flows with a teammate.
- Fix one small bug or documentation issue to learn the local workflow.
- Use `/explain-codebase --onboard` to generate a project-specific checklist.
